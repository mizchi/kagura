# math3d

`Vec3`、`Vec4`、`Mat4`、`Quaternion` と有限線分 `Segment3` の純粋な幾何計算。

`Segment3::new(start, end)` の `closest_point(point)` は線分の両端を含む最近点を返す。
`distance_squared(point)` は距離の二乗で、球やカプセルの接触判定では半径の二乗と比較できる。
ゼロ長なら始点との距離を返す。入力には有限のワールド座標を渡す。
線分の長さにゲーム固有の上限や下限を設けないため、極端に短い／長い移動にも使用できる。
境界を接触として含めるかは、呼び出し側が `<` と `<=` で選択する。
