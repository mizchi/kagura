# Arena 3D

収集・射撃・ジャンプと剛体物理を試すサンプル。FPS Demo の操作を統合し、一人称と三人称で同じプレイヤー・照準・ワールドを共有する。

起動はリポジトリ直下で `just dev arena3d`。Pages のビルドでは `/arena3d/`、Studio では Examples の Arena 3D を開く。

| 入力 | 操作 |
|---|---|
| WASD / 矢印 | 視線に対して移動 |
| Space | ジャンプ |
| 左クリック / F | 射撃 |
| 右ドラッグ | 視線を動かす |
| Q / E、I / K | 左右、上下に視線を動かす |
| V | 一人称・三人称の切り替え |
| R | 現在のステージをリセット |

黄色いアイテムは10点、赤い敵を撃つと25点。敵に触れると終了し、Rで再開できる。水色の床を踏むと次のシーンに移動する。

四方を高さ3mの壁で囲み、箱6個・球3個・手すり付きの滑り台を配置する。上空の3つの枠から順番に0.9秒間隔で球を落とし、滑り台の上に落ちた球は斜面を転がって場内に出る。追加の球は24個で循環し、小道具33個とプレーヤーを合わせて最大34個の動的剛体に制限する。Rで配置と落下タイマーをリセットする。

プレーヤーも同じ物理ワールドの剛体として動く。球や箱にぶつかられると押され、逆方向の入力で踏ん張れる。入力は目標速度へ近づける力として加え、無入力時は弱いブレーキ、空中では弱い操作力を使う。斜面では接地面に沿って移動し、ジャンプは上向きの力積を与える。開けた床の外へ落下した場合はプレーヤーだけを現在のシーンの出現地点へ戻す。

弾は毎秒16mで飛び、明るい弾体と短い軌跡を表示する。到達時に最も手前の物体へ命中し、箱や球には力積を与える。着弾表示は0.2秒残る。毎フレームの移動区間で衝突を検査し、壁や床は射撃を遮る。Studio の `crate`、`ball`、`slide`、`ball_dropper` 部品で配置できる。滑り台は位置と幅・高さ・奥行きを指定し、傾いた床板と手すりを生成する。

- `scenes/training.mbt`: 床・壁・箱・球などの配置
- `controls.mbt`: 視点、移動方向の入力、固定された地形・壁によるカメラの障害物回避
- `physics.mbt`: `core/physics3d` への接続、表示用の剛体参照
- `shooting.mbt`: 弾の速度・射程・上限、飛行中の衝突照会、軌跡・着弾表示
- `physics_yard.mbt`: 滑り台の形状・当たり判定、球の定期落下と循環
- `player_physics.mbt`: プレーヤー剛体、移動モーターの接続、ジャンプと復帰
- `game/character3d`: 他のゲームにも使える移動モーターと接地照会
- `view.mbt` / `hud.mbt`: シーンと操作表示

箱は回転を固定したAABB、球はSphere、滑り台は回転付きのBoxを使用する。斜面の描画・衝突・射撃照会は同じ形状を参照する。60Hzの固定ステップで更新し、描画メッシュは再利用する。射撃で剛体を追加せず、弾と着弾表示は計12発、1発につき最大5メッシュに制限する。射程40mで消滅し、リセットやシーン移動時にも消去する。

```sh
just arena-physics-test
just target=native arena-physics-test
moon -C examples/games/arena3d bench . --target js --release
```

`game_bench.mbt` は落下球を上限まで生成した状態で、更新・物理ステップ・シーングラフと描画コマンドの構築を測る。GPU描画やブラウザへの転送時間を含まない。実入力の回帰確認は `e2e/pages-arena.spec.ts` と Studio の `e2e/scene-patterns.spec.mjs` にある。

床抜けの回帰テストは `core/physics3d/floor_regression_wbtest.mbt` と `rain_wbtest.mbt` にある。大きな床の端での接触点、AABBの回転固定、高速移動時の薄い床・壁との衝突、球を落としながら箱に力を加える60秒分のシミュレーションを検証する。静的な箱への高速移動は移動区間も検査する。回転付きBoxの接触は単一の代表接触点を使い、連続衝突検査は並進を対象とする。
