# Network Sync Plan

マルチプレイヤー対応は、シングルプレイヤーのゲーム体験が十分に固まった段階で着手する。

## 方針

- WebSocket ベースで実装する（WebRTC は使わない）
- まずは協力プレイ（2-4人）の最小構成を目指す

## 前提条件（着手の目安）

- ゲームループとステート管理が安定している
- セーブ / ロードが動いている
- host / guest 間の ABI が固まっている

## 検討事項

- サーバー権威モデル vs クライアント予測
- 同期対象の選定（プレイヤー位置、敵 HP、アイテムドロップ等）
- レイテンシ補償
- ロビー / マッチメイキング
