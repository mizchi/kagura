# Card game: 分岐・固有エネミーの実装と検証（2026-10-03）

3レーンの分岐マップから部屋を選び、戦闘、イベント、ショップ、休息、宝箱を通って2幕・30階を進むランを実装した。通常ランとJevは同じ `RunState::adventure`、`run_choices`、`apply_run_choice` を使用する。既存のバランス分析用の固定順序は `RunState::new/start` に残した。Guardian Trialは従来どおりボスから開始する。

## 追加した挙動

- 接続先だけを選べるマップ。現在地、通過済み、次の候補を表示し、他の階も閲覧できる。14階は休息、15階はボス。第1幕のボス報酬後は全回復して第2幕を開く。
- 開始時99ゴールド。通常・エリート・固有エネミー・ボスで報酬額を変え、勝利報酬の二重取得を拒否する。
- 4種類のイベント。HP・ゴールド・所有レリックを判定し、費用を明記して支払えない選択肢を無効にする。
- ショップのカード・レリック・ポーション購入とカード削除。売り切れ、所持金、ポーション枠を判定する。削除の料金は対象の確定時に支払い、取り消しでは支払わない。
- 宝箱では未所持の通常レリックから1つ選ぶ。候補を重複させず、全種類所持済みなら60ゴールドを付与する。
- Cinder Duelist、Gilded Sentinel、Hollow Oracleの3種類の固有エネミー。独自の4ターン周期、専用ドット絵・色、専用レリックを持つ。同じランで再登場しない。
- 専用レリックはEmber Seal（開始時Strength +2）、Merchant Charm（購入・カード削除20%割引）、Wayfinder（戦闘ゴールド +10）。通常のショップ・宝箱では出現しない。

画面操作は共通UIの方向・確定・取消イベントに接続した。ポインターの当たり判定と描画は共通矩形を使う。部屋の選択と購入は400msのフェード中に入力を消費し、連打で二重実行しない。デッキモーダルを閉じた後は起点だけにフォーカスを戻し、確定はモーダルの再表示、方向入力は部屋の選択へ移る。

## 自動検証

TDDで、未実装の分岐API、ゴールド取引、固有行動、レジストリの上限、表示記号、削除対象のページ追従、モーダルの単一フォーカスを失敗するテストから実装した。

| 検証 | 結果 |
| --- | --- |
| `just card-game-test` | ゲーム199件をJS/nativeで通過。共通UI、scene、raster、releaseビルド、Node API/CLI、Webホストの検証も通過 |
| `just card-game-e2e` | Chromiumヘッドレスの28件を通過 |
| renderer2d | JS/nativeとも105件を通過。`<`、`?`、`$`の描画を追加検証 |
| 初期状態レジストリ | JS/nativeとも3件を通過。64状態を許可し65状態を拒否 |
| UI matrix | 40状態×5サイズ、200画像の全件で完全描画・状態・フォーカス・palette・vlmkit integrityと画像幾何検査を通過 |
| 画像差分 | 同じ200画像を再描画して基準と比較し、差分0 |

Playwrightでは分岐の到達制約、固有戦闘・ショップ・宝箱への接続、支払えないイベント、購入の連打、削除の取消と料金、レリックの所持確認、固有エネミーの防御継続、専用報酬から次の分岐への復帰、モーダルのフォーカス復帰を確認した。縦長で起動した画面と、ブラウザのCSSサイズを変えた後の座標入力も確認した。ブラウザのCSS変更ではゲームの論理サイズを保つ。

最初の画像検査では通過済みノードの文字コントラストが3.82:1だったため、文字色を修正した。修正後は全サイズで検査を通過した。レリックのHP条件にある`<=`・`>=`は、フォントで消えないよう`AT MOST`・`AT LEAST`へ変換して表示する。Canvas内の要素はDOMでは列挙できないため、PNGとシーンのUI snapshotを対応させ、vlmkitがスキップする規則を画像幾何・画素コントラストの検査で補った。

## Jevの実APIによるラン

`~/.profile`のキーと実際に使ったキーが一致すること、ログにキーが含まれないことを値を表示せず確認した。要求モデルは`jev-latest`、応答モデルは`jev-1.13.0`。Node 24.21.0で描画なしに実行した。

| 条件 | 結果 |
| --- | --- |
| Warden / Ascent、seed42、上限500判断 | 264判断で30階のボスを倒しラン勝利 |
| 最終状態 | HP58/105、161ゴールド |
| 実行時間 | 50.850秒 |
| 判断時間 | 中央値184ms、95パーセンタイル250ms |
| API使用量 | 入力1,244,958トークン、出力17,537トークン、264リクエスト |

マップを30回選択し、通常戦4、エリート2、ボス2、イベント7、休息6、宝箱6、ショップ3を通った。ショップではカード・レリック・ポーションを購入した。このランでは固有エネミーの道を選ばなかったため、その戦闘と専用報酬はMoonBitとPlaywrightで別に検証した。すべての判断はゲームが提示した合法手に含まれた。

この1ランは複数シードでの勝率評価ではない。seedはゲームの乱数を固定するが、モデルの判断は固定しない。再現は判断ログを使う。

```bash
just card-game-agent --no-build --seed 42 --character warden --stage ascent \
  --max-decisions 500 --quiet --out output/route-review/jev-adventure-final-seed42.jsonl
just card-game-agent --no-build --replay output/route-review/jev-adventure-final-seed42.jsonl
```

再生ではAPIを呼ばず、初期状態、各判断の前後、最終状態がすべて一致した。観測とログはv2で、分岐導入前のv1ログは受け付けない。`room`とマップの`current`は文字列・数値またはnullとして提供する。
