# AFTERSHIFT

夜の搬入口を進む、短いベルトスクロールアクション。敵の予備動作を読み、奥行き方向へかわし、攻撃後の隙へ反撃するのが核です。3区画を突破して、最後の FOREMAN を倒すとクリアします。

## 遊ぶ

```sh
just belt-action-dev
# http://localhost:5195
```

ブラウザの WebGPU が必要です。初回の依存はタスク内で準備します。Studio の Examples からも AFTERSHIFT を開けます。スマートフォンでは横向きを推奨します。

| 操作 | キーボード | コントローラー | タッチ |
| --- | --- | --- | --- |
| 左右・奥行き移動 | WASD / 矢印 | 左スティック / 十字キー | 方向ボタン |
| 通常の3連撃 | J（長押し可） | A / South | 連撃 |
| ガード崩し | K（長押し可） | X / West | 崩し |
| 回避 | Space | B / East | 回避 |
| 開始・再開・再挑戦 | Enter | Start | 上部のプレイ / 再開 / もう一度 |
| 一時停止 | Esc | Back | 一時停止 |
| 最初から再挑戦 | R | — | クリア・敗北後にもう一度 |

琥珀色のジャケットがプレイヤーです。敵の床の予告帯から上下へ外れると攻撃を避けられます。盾持ちは正面の通常攻撃を防ぐため、隙の大きい K で崩すか、背後を取ります。通常連撃の3発目は強く吹き飛ばします。回避は無敵時間がありますが、再使用まで待ち時間があり、通常攻撃とガード崩しの後半からキャンセルできます。

盾持ちとボスの **BRACED** 表示中は、正面から K を当てても予告中の攻撃を止められません。床の予告帯から外れて空振りさせ、**OPEN** と出たら反撃します。方向を入力しながら回避するとその方向へ移動し、背後を取って正面の防御を避けられます。方向指定のない回避は後退します。盾を崩した後の隙は一定時間で終わり、追撃では延長できません。ボスはのけぞり続けません。

初期の調整では J 長押しだけでクリアできたため、この防御・反撃の周期を追加しました。プレイヤーの最大HP6、基本ダメージ1、敵のHPは据え置きです。

見てから操作を選ぶ時間を確保するため、標準のタイミングを次にしています。

| 場面 | 猶予 |
| --- | --- |
| 通常敵・ランナーの予告 | 1.0秒 |
| 盾持ちの予告 | 1.2秒 |
| ボスの予告 | 1.4秒 |
| 空振り後の OPEN | 通常1.5秒、ボス1.8秒 |
| 次の敵が攻撃を始めるまでの間 | 最低0.4秒 |
| Kから回避へ移れる時点 | 攻撃開始から約0.33秒 |

敵のバーで予告の進み具合と OPEN の残り時間を示します。床の予告帯は実際の攻撃判定と同じ幅です。強敵が攻撃を当てたときは防御を立て直し、空振りしたときに長い反撃時間が生まれます。

検証では、敵の予告・OPENを認識してから500 ms入力を保留します。100 msごとの即時判断を、人間向けの難易度の基準には使いません。自動で接近する攻撃連打13パターンは敗北を検証します。回避も混ぜた4パターンは結果と被害を記録し、すべてを敗北させることを調整の合格条件にしません。

## 後で行う微調整

現在の数値は暫定です。実プレイを見ながら、以下を再調整します（2026-11-11 記録）。

- [ ] 初見で予告・OPENを認識し、回避・反撃が間に合うか確認する。予告時間・反撃時間・表示を調整し、自動テストの成功だけで難易度を確定しない。
- [ ] 盾持ち・ボスとの駆け引き、複数敵の圧、壁際の退路を確認する。連打と狙った回避・位置取りの差を調整する。
- [ ] キーボード・ゲームパッド・タッチの操作感を確認する。回避距離・キャンセル・先行入力と、ヒットストップ・効果音・ノックバックの手応えを調整する。

## 試作の判断と参照

`sakurai-game-design` の同梱要約を参照しました。以下は今回の実装への応用です。数値は本試作用の調整値で、桜井氏の基準ではありません。

- [リスクとリターン](https://www.youtube.com/watch?v=cTSMohV3TgQ)：素早い連撃に対し、ガード崩しは発生と硬直を長くする。敵も予備動作・攻撃・後隙を分け、反撃する判断を作る。
- [大事なところはストップ!](https://www.youtube.com/watch?v=APOD1fmwPaM)：命中時に通常5・強打8フレームの停止、ヒットマーク、ノックバック、短い効果音を重ねる。停止中も入力を保持する。
- [リトライは迅速に](https://www.youtube.com/watch?v=xmQeUoKpTqg)：開始・再挑戦は1操作で実行する。通常攻撃の長押しが結果画面を消さないようにする。

試す問いは「床の予告を見て攻撃前に避けられるか」「盾への空振りと命中を見分けられるか」「通常連撃と崩しを使い分けたくなるか」です。自動テストは操作と進行の成立を確かめます。面白さや音の聞き取りやすさは、実プレイで引き続き調整する対象です。

## 構成・調整

- `sim/`：描画・ブラウザに依存しない60 Hz の状態、戦闘、敵AI、区画進行、入力バッファ。
- `main.mbt`：固定刻み更新、入力の合成。`view.mbt`：Scene API による描画。外部素材なし。
- `assets/host.mjs`：ブラウザの短い入力の保持、タッチ操作、Web Audio 効果音。戦闘ロジックは持たない。
- `inspection.mbt`：Studio の型付き観察・編集。停止中だけ HP 1〜6、現在区画内の X、奥行き300〜445、ダメージ1〜4、敵の基本予告36〜120フレームを編集できる。revision と区画 scope を検証する。

Studio の Pause はゲーム内のポーズメニューを開かず、そのままの戦闘画面を凍結します。Player・Combat・各敵を観察できます。HPゼロ、敵のHP、進行状態、スコアの書き換えは公開していません。全状態復元・Undo・Step・checkpoint は未対応です。

```sh
just belt-action-test  # MoonBit JS / native
just belt-action-e2e   # 実キー・タッチ、連打での敗北、回避を使った全区画クリア
```

3区画・7体の小さな試作です。保存、装備、分岐、複数ステージは扱いません。
